# Community guidelines

Help people feel safe asking basic questions. Be patient, clear, and respectful. Critique ideas and code rather than the person behind them.

Harassment, threats, discrimination, personal attacks, and sharing another person's private information are not welcome. Never ask someone to post credentials or private migration records to prove a problem.

These rules apply to project issues, pull requests, and other spaces maintained by the project. Maintainers may edit or remove harmful content, close discussions, or restrict participation. They should explain the decision where doing so does not reveal private information.

To flag harmful public content, use GitHub's **Report content** option and choose **Report to repository admins** when available. Use GitHub's platform reporting route for threats or abuse when a repository route is unavailable. Do not repost the harmful material or private details in a new public issue. For a vulnerability in the kit, use [SECURITY.md](SECURITY.md).
